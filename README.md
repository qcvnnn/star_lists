# Каталог звёзд

Учебное веб-приложение с мобильным интерфейсом: лента звёздных систем, каталог карточек и страница черновика.

**Стек:** Python, FastAPI, Jinja2, HTML, CSS, JavaScript.

## Возможности

- Просмотр опубликованных карточек и переход к следующей записи.
- Каталог с фильтром по дате.
- Отображение описания, числа планет и количества отметок «нравится».
- Отдельная страница демонстрационного черновика.

Данные находятся в Python-коллекции. Расчёт орбит и научная оценка обитаемости в этой версии не реализованы; количества и описания используются как содержимое карточек.

## Запуск

Python 3.10+. Команды для PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install fastapi uvicorn jinja2
python main.py
```

Откройте:

- `http://127.0.0.1:8000/feed` — лента;
- `http://127.0.0.1:8000/catalog` — каталог;
- `http://127.0.0.1:8000/draft` — черновик.

В текущей ветке `requirements.txt` пустой, поэтому зависимости перечислены в команде установки. Запускать нужно из корня проекта.

## Ограничения

Авторизация, постоянное хранение изменений и публикация записей не реализованы. Часть адресов медиа указывает на локальный MinIO: без загруженных в него объектов эти ресурсы недоступны. `docker-compose.yml` запускает только хранилище, а не всё приложение; для просмотра интерфейса основной сервер запускается отдельно.
