# Допзадание по Tauri и CLIP

Нативное Windows-приложение «Звёздные системы» показывает каталог и подробности карточек. Оно получает данные из FastAPI по IP в локальной сети. При поиске по фото CLIP сравнивает изображение с английскими описаниями карточек. Приложение показывает одну лучшую карточку, если её оценка не ниже 0,64.

## Запуск

Скопируйте .env.example в .env, настройте PostgreSQL и MinIO, запустите сервисы и установите зависимости из requirements.txt. Примените миграции командой python -m alembic upgrade head. Запустите FastAPI на порту 8000, указав локальный IPv4 в параметре --host.

В папке native выполните npm ci и npm run tauri -- build. Запустите собранный .exe и введите IP сервера в поле приложения. При первом поиске приложению понадобится интернет для загрузки весов CLIP.
