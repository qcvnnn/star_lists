В базу PostgreSQL добавлено 100 100 учебных карточек. В каталоге можно выбрать дату получения, посмотреть число совпадений и перелистнуть результаты. React передаёт серверу дату и номер страницы, а сервер возвращает по 10 карточек. Например, за 14 января 2025 года найдено 138 карточек, которые занимают 14 страниц. Чтобы база быстрее находила опубликованные карточки за нужную дату, добавлен индекс по дате и ID. В контрольном замере один и тот же запрос выполнялся 0,050 мс с индексом по дате и 2,939 мс без него. Лента работает отдельно от каталога. При первом открытии сервер выбирает 100 случайных карточек и сохраняет их ID в Redis в порядке показа. Подборка привязана к сессии гостя или вошедшего пользователя. Сами карточки читаются из PostgreSQL. После последней карточки сервер формирует новую подборку. В проверке обе подборки содержали по 100 карточек без общих ID.
