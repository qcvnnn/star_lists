# Нативное приложение Звёздные системы

Это приложение для Windows с двумя экранами: каталогом и карточкой «Подробнее». В каталоге можно отфильтровать системы по названию и дате получения. В карточке видны изображение, описание, дата получения и число планет в зоне обитаемости.

Интерфейс написан на React и собран в отдельное приложение через Tauri. Часть на Rust обращается к FastAPI по IP локальной сети. Поэтому после изменения описания в PostgreSQL достаточно обновить каталог, чтобы увидеть новый текст в приложении.

Для поиска по фото используется CLIP. Модель сравнивает загруженное изображение с коротким английским описанием каждой карточки. Поиск показывает одну карточку с наибольшей оценкой, если она набрала хотя бы 0,64. Если подходящей карточки нет, выдача остаётся пустой. Например, по обложке TOI-700 приложение нашло карточку этой системы с оценкой 0,647 на демонстрационном скриншоте.
