# Оценка экзопланет в зоне обитаемости звёзд

## О проекте
Приложение для оценки количества экзопланет, находящихся в зоне обитаемости звёзд.
**Услуга:** список звёзд с характеристиками.
**Заявка:** расчёт радиуса зоны обитаемости и вероятного количества планет.

---

## Ветка: feature/frontend-layout

Реализован дизайн и вёрстка трёх страниц мобильного приложения:

1. **Лента** — видео с информацией о звезде (описание, радиус зоны, кол-во планет, лайки, кнопка «Следующий»)
2. **Добавление** — черновик с полями (медиа + текст)
3. **Плитка** — список звёзд в 2 столбца с фильтрацией по радиусу зоны обитаемости

### Функциональность
- Коллекция звёзд с полями: название, радиус зоны (мин/макс), кол-во планет, масса, тип, описание, лайки, статус
- Статусы: `черновик`, `опубликован`, `удален` (удалённые скрыты)
- Фильтрация по радиусу зоны обитаемости
- Лайки вычисляются из коллекции

### Технологии
- HTML5, CSS3 (отдельный файл), JavaScript (vanilla)
- Дизайн в стиле AstroAlert (`#0A0E17`, `#6C63FF`)
