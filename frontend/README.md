# Звёздные системы — React, лабораторная №5

## Запуск
```shell
npm install
npm run dev
```
Папка проекта: `frontend`. Node.js 22. Проверка и сборка: `npm run build`.

## Три страницы
- `#/feed` и `#/feed/16` — лента. Видео, название, описание, дата, число планет и лайков. «Больше/Меньше» раскрывает текст. Стрелка открывает следующую звезду; после последней — первую.
- `#/catalog` — плитка «Все системы». Фильтр по точной дате получения, кнопки «Найти», «Сбросить». Нажатие на карточку открывает выбранную звезду в ленте. Отдельной подробной страницы нет.
- `#/draft` — страница добавления/черновика с прежними полями: фото, видео, название, описание, дата, количество планет, публикация. Макет заполнен из `src/data/draft.ts`. Для гостя поля и публикация отключены. Для демонстрации третьей страницы открыть её по прямому адресу.

Нижний Navbar: Лента, Добавление, Плитка, Вход. По ТЗ доступны только Лента и Плитка. Авторизация и создание записей в этой лабораторной не выполняются.

## Данные и медиа
Все карточки — `src/data/stars.ts`, черновик — `src/data/draft.ts`. API, Redux, Context не используются. В Network загружаются только файлы фронтенда и локальные медиа.
`src/components/Media.tsx` подставляет `src || DEFAULT_IMAGE` и `src || DEFAULT_VIDEO`. Файлы находятся в `public/media/default-star.jpg` и `default-star.mp4`. Ошибка загрузки также включает запасное медиа. У Gliese 667 C (id 16) и Kepler-442 (id 20) медиа пустые — можно показать подстановку.

## Компоненты, props и хуки
`App` передаёт в `CatalogPage` список звёзд, дату и обработчики. `DateFilter` получает `value`, `onChange`, `onApply`, `onReset`. `StarCard` получает `star`. Фильтр применяется по нажатию «Найти», сбрасывается кнопкой «Сбросить»; пустой результат показывает подсказку.
`useState`: адрес, введённая/применённая даты в App; раскрытие описания в FeedPage; ошибки медиа в StarImage/StarVideo.
`useEffect`: подписка на hashchange с очисткой слушателя и изменение заголовка вкладки. Hash-маршруты открываются без перезагрузки, React Context не требуется.
React-Bootstrap: Card, Form, Button, Navbar, Nav. TypeScript описывает объект Star и props; Vite собирает приложение.
