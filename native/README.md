# Звёздные системы. Нативное приложение

Гостевой каталог и страница «Подробнее». Приложение читает из FastAPI опубликованные карточки с английскими описаниями для поиска. Поиск по названию и дате работает одновременно с поиском по фото. Загруженное изображение обрабатывается на компьютере и не передаётся в API.

## Сборка

Из папки бэкенда выполните `python -m alembic upgrade head`. Найдите IPv4 активного адаптера командой `ipconfig` и запустите веб-сервис на этом адресе. На машине автора использовался:

```powershell
python -m uvicorn main:app --host 172.16.242.254 --port 8000
```

Из папки нативного приложения:

```powershell
npm ci
npm run tauri -- build
```

Откройте собранный `src-tauri/target/release/star-lists-native.exe`. При сборке с явным `--target x86_64-pc-windows-gnu` путь будет `src-tauri/target/x86_64-pc-windows-gnu/release/star-lists-native.exe`. Оставьте `WebView2Loader.dll` рядом с `.exe`. Адрес можно изменить в интерфейсе. Rust проверяет, что это IPv4 частной сети, и запрашивает `http://<IP>:8000/api/star_list/native/catalog`.

## Поиск по изображению

CLIP строит векторы фотографии и поля `clip_description`. В базе подготовлены описания длиной 50–100 символов. Поиск сортирует карточки по косинусному сходству, приведённому к диапазону 0–1 по формуле `(cos + 1) / 2`. Порог — 0,64 (сырой косинус 0,28), TopK — 3. На четырёх обложках из MinIO первое место заняли соответствующие карточки с оценками 0,6433–0,6623. Порог 0,65 исключил бы два правильных совпадения. TopK ограничивает выдачу тремя карточками, а порог убирает слабые совпадения. Это замер на учебных обложках, а не на произвольных фотографиях. Настройки находятся в `src/clip.js`.

[Методические указания Tauri](https://github.com/iu5git/Web/tree/main/tutorials/tauri)

Повторить замер с текущими обложками сервера можно командой `node scripts/calibrate.mjs 172.16.242.254`.
